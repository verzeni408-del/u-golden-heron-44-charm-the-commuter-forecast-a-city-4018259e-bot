Entry for the [make.fun](https://make.fun/c/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e) competition **"Charm the Commuter: Forecast a City That Isn't"**.

`main.py` (Python stdlib only) writes a one-line, 111-character weather forecast for Brindlewick — a city that isn't — to `/output/entry.txt`. The entry is exactly 111 characters (113 bytes UTF-8), one line, no trailing newline — well under the 140-character limit.

> In Brindlewick, drizzle until 9 AM, then sunshine. The 8:15 bus is on time for once — check if you're dreaming.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
